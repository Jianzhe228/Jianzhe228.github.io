## Project Overview

Hexo 8.x static blog hosted on GitHub Pages at **www.228610.xyz**. Content is primarily in Chinese.

## Commands

```bash
# Install dependencies
pnpm install

# Local dev server (http://localhost:4000)
pnpm server

# Generate static site to ./public/
pnpm build

# Clear build cache (db.json, public/)
pnpm clean

# Full rebuild
pnpm clean && pnpm build
```

**Blog management tool** (`blog.py`) — interactive Python script for creating, editing, and deleting posts. Auto-commits and pushes after each operation. Requires `pyyaml` and `trash-cli`.

## Architecture

- **Hexo config**: `_config.yml` — site settings, permalink pattern (`:year/:month/:day/:title/`), theme `landscape`, pagination (10/page)
- **Posts**: `source/_posts/*.md` — ~106 blog posts with YAML front matter (title, date, categories, tags)
- **Category pages**: `source/<category-name>/index.md` — 64 category landing pages
- **Scaffolds**: `scaffolds/` — templates for `hexo new` (post, page, draft)
- **Custom search**: Local search overlay replacing theme's native search
  - `scripts/local-search.js` — Hexo injector that inserts search UI into all pages
  - `source/js/local-search.js` — Client-side search logic (parses `/search.xml`, multi-keyword AND matching, highlighting)
  - `source/css/local-search.css` — Search modal styling
- **Theme**: `hexo-theme-landscape` via npm (no local theme overrides in `themes/`)

## Post Front Matter Format

```yaml
---
title: Article Title
date: 2024-01-01 12:00:00
categories: Category Name
tags: [tag1, tag2]
---
```

## Deployment

GitHub Actions (`.github/workflows/deploy.yml`) auto-deploys on push to `main`:
1. Node.js 20 + `npm install`
2. `npx hexo generate`
3. Publishes `./public/` to GitHub Pages via `peaceiris/actions-gh-pages@v4`

## Key Conventions

- Package manager: **pnpm** (lock file is `pnpm-lock.yaml`)
- Category directories in `source/` must have a matching `index.md` with `type: categories` or appropriate layout
- Search XML is generated by `hexo-generator-searchdb` at `/search.xml`
